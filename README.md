# Statdoatie 🐾
**The Kad Stat Tracker and Kadmmunity hub.**

Dont you love feeding Kads? Dont you wish you had a cool, attractive way to keep track of your feeds? do you like number go up? do you like seeing a BUNCH of numbers go up?

good news

Statdoatie works a lot like itemDB's restock dashboard — there's a companion userscript that watches you feed kads in the background, and when you're ready you sync the data to the dashboard. It only tracks from the moment you install the userscript, so it'll take a little while to build up meaningful stats. Worth it though.

---

## Get started

**[→ Open the dashboard](https://dinosauringg-ui.github.io/Statdoatie/)**

**[→ Install the userscript on Greasy Fork](https://greasyfork.org/en/scripts/581360-statdoatie-analytics-sync)**

You'll need [Tampermonkey](https://www.tampermonkey.net/) (or a browser that supports it) to run the userscript.

---

## What's in it

- Kads fed, win rate, NP spent, active days, feeding streak
- Feed activity heatmap, daily/hourly charts, item price tiers
- Live item pricing via itemdb.com.br
- **Kadmmunity** — a community leaderboard for top feeders, bottom feeders, NP spent, win rate, and a global activity heatmap
- Seven themes because why not

---

## Kadmmunity

Enter your Neopets username in the Kadmmunity tab and hit Submit. Honor system — use your real username. Weekly stats reset naturally, all-time stats keep climbing.
