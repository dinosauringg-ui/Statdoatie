How to Use Statdoatie
  1. Install the Extension: Make sure you have the Statdoatie Tampermonkey extension active on Neopets.
  2. Feed Kads: The extension will quietly track your successful feeds and snipes in the background.
  3. Sync Data: Come back to this dashboard and click the Sync icon in the top right. The extension will beam your latest data right into the app.
  4. Item Value DB: The dashboard automatically grabs current ItemDB prices so you know exactly how much you're spending.
